## 二、主要字段字典

完整表列、类型、默认值和主键见 [字段字典](data-dictionary.json)。SQLite 使用幂等建表及 ALTER 迁移，业务关联通过代码维护，并结合事务和对账验证一致性；外键强约束覆盖作为后续工程增强项。

| 表 | 关键字段 | 语义与限制 |
|---|---|---|
| courses | id、display、score、knowledge_taxonomy、enabled | 课程身份、分值、大纲JSON与启用状态 |
| knowledge_points | id、course_id、chapter、name、difficulty | 课程下知识点；difficulty为1—5工程基线，非IRT标定 |
| problems | id、course_id、source、type、stem、answer、verification_type、func_name、ref_code、citations | 题干、参考答案或canonical JSON、判分类型、代码入口和出处 |
| problem_knowledge | problem_id、knowledge_id、weight | 题目与知识点多对多，weight默认1 |
| test_cases | problem_id、input、expected_output、hidden | JSON参数与期望结果；hidden样例不直接公开细节 |
| rubric_items | description、score、expected_evidence | 可解释的规则得分点及分值；复杂语义结合模型说明与人工复核 |
| chunks | text、course、doc_type、source、title_path、page_start、page_end、chunk_index | FTS正文及引用定位；0页表示材料无真实页码 |
| chunk_hashes | hash、course、source、chunk_index | 课程＋归一化正文哈希，支持内容去重 |
| users | username、role、pw_hash、salt、status、资料字段 | 账户权限、盐化散列及个人资料；生产行和原密码不交付 |
| learning_sessions / dialog_turns | username、intent、state；session_id、role、content、structured_data | 学习会话、轮次、引用与生成结构；按用户归属访问 |
| tutor_snapshots | db_session_id、session_id、username、snapshot | TutorGraph状态恢复，snapshot含JSON |
| practice_attempts | username、problem_id、knowledge_id、session_id、answer、score、hints_used、duration | 用户作答、判分、提示及耗时秒；自由题可problem_id=0 |

| review_plans / tasks | start_date、exam_date、budget_snapshot；stage、minutes、due_from/to、tier | 复习计划、预算快照、间隔、到期窗与必做选做 |

## 三、预处理流程

资料：按课程／资料类型发现文件，解析PDF、PPTX、DOCX、TXT，扫描件需视觉OCR；保留页码或标题。按章节／页／标题分块，长文兜底切分；按课程与规范化文本SHA-256去重，写入FTS。撤下资料移到withdrawn，不再被raw重扫；恢复重新解析。

题库：抽取／生成题统一课程与知识点，规范选项和canonical答案；代码参考解经样例检查，概念题保存得分点，生成题保存引用。题目入库与验证状态分开管理，按实际状态组织自动验证、模型辅助和人工复核；下一阶段通过答案规范化与kind扩展提升验证覆盖。训练样本通过格式、结构与验证筛选，按课程／任务组织；复训时依据实际资产重新审计held-out与训练去重。

学习记录：统一judge_answer判分后保存作答、更新掌握度、存错题／销错题，复习与班级统计读相同关联。教师复核保留AI原错因，向学生提供结论和备注；合成示例明确标注来源，不作为真人实验样本。

## 四、脱敏与交付策略

下载包从内容表白名单导出处理后数据，从零创建虚构身份；初始作答、会话、学习记录、复核及通知等个人表为空，签名密钥按实例独立生成。ACCESS.md仅管理本地演示账号，其密码与线上凭据分离；线上评审账号通过比赛指定渠道单独交付。真实姓名、学号、手机号、邮箱及头像不进入演示库，合成班级显式命名比赛演示班。

独立测试只从白名单courses/app_settings/knowledge_points/problems/test_cases/rubric_items/problem_knowledge读取内容表，复制FTS供实际规模测试；身份与行为全新。最终数据包从内容表白名单独立导出，app_settings与FTS构建环境元信息保持为空；评审账号重新创建。发布前扫描提交文件、ZIP/DOCX结构、已知线上密钥字节和运行库，核对导出清单及脱敏结果。

实验数据JSON采用内容表白名单聚合、schema与源码摘要，省略实际部署位置、用户统计和个人行为信息。ACCESS.md提供本地虚构演示凭据；公开数据授权与来源署名按PUBLICATION.md及第三方说明分别核对。

## 五、适用范围与合规要求

处理后内容包提供四课程完整内容部署与比赛评审；源码bootstrap另提供原创轻量复现样例。来源署名与脱敏分别管理：署名用于追溯，脱敏用于保护个人信息。第三方教材、课件、真题、OCR及派生样本遵循权利人授权，公开、训练及商业再分发按对应许可执行。

合成学习轨迹用于业务流程验证，历史teacher-gold用于蒸馏一致性评价；真实学生分布、长期教育效果和掌握度参数标定需另设真人样本与独立评价设计。个人信息遵循最小化处理原则，禁止重识别、关联学校名单或对外传播。模型API开启时，按供应商数据政策和学校规定审查输入，身份或受限版权材料须完成合规审查后方可发送。
