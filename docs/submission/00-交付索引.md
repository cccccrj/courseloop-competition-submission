## 二、评委建议阅读与体验顺序

先阅读 README 和本索引，按部署说明启动本地系统，或通过比赛指定渠道单独获取线上体验地址与评审账号，体验四课程、带依据的文本问答和已启用的拍照批改。真实图片转写与公网拍照流程证据见测试报告；下载包不附模型密钥。随后阅读技术报告与测试结果。需要教师／教务权限或复核协同体验时，启动本地交付内容库，用 ACCESS.md 中对应角色切换，不向评委开放生产教务管理权。

本地提供无密钥基础模式，可体验课程、题库、确定性判分、错题、学情、复习和教学工作台；配置API后开启模型讲解与出题。流程桩验收与真实模型调用分别记录，便于核查各自的验证范围；真实视觉证据见artifacts/evidence/v1.0/vision-live.json。

## 三、总仓库组织

| 路径 | 内容 |
|---|---|
| backend/ | API、鉴权、数据层、导学智能体、RAG、验证器与学习模型 |
| frontend/ | Vue 页面、角色导航、API/SSE 客户端、公式和代码渲染 |
| scripts/ | 原有数据工程／训练评测脚本及本次 submission_* 交付工具 |
| tests/ | 原有测试及新增事务、并发、视觉和GPU交付层回归用例；本次621项源码回归通过，历史GPU源码回归604项 |
| deploy/ | systemd、Nginx 和备份模板，需按部署地址自行配置 |
| docs/submission/ | 9份正式报告（00—08）、字段字典、数据清单、证据规则与演示入口 |
| artifacts/evidence/ | 测试 JSON、JUnit、日志、截图、源码和数据盘点 |
| ACCESS.md | 本地虚构演示账号与线上凭据分发说明 |
| requirements*.txt | 轻量运行、经过验证的提交环境锁定、可选研究依赖 |

Git 不纳入 .env、签名密钥、运行数据库、真实用户记录、第三方教材正文或模型权重。下载运行包在Release；v1.0按[处理后数据交付范围](处理后数据交付范围.md)提供4810题、2646检索块及配套判题内容。部分数据来源于南京理工大学计算机科学与工程学院本科生自建数据库。正式交付文档统一集中在本目录，配套架构图见docs/diagrams。

v1.0对应完整处理后内容交付，环境对应关系见 [README环境表](../../README.md)。完整交付清单见本索引第一节。

## 四、运行方式与扩展计划

当前线上文本和视觉模型通过外部OpenAI兼容API运行，支持轻量无卡部署。视觉使用智增增qwen3-vl-30b-a3b-instruct，独立端点与密钥保持文本服务配置；原创印刷体图片与公网拍照流程已完成验收，广泛手写和扫描件准确率作为后续专项评测。4090D独立部署已完成现有Qwen3-14B-FP8与LoRA的单请求、长上下文及4／8路并发计时、显存和吞吐验证，见08专项报告；在线演示环境保持原部署，历史训练报告单独归档。演示视频与答辩PPT已纳入V1.0附件，入口及校验信息见[演示材料与文件校验](演示材料.md)。
