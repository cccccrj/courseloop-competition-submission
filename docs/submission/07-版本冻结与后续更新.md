# CourseLoop 版本冻结与后续更新协议

## 一、版本和数据口径

唯一正式提交版本为v1.0，仓库仅保留main分支与v1.0标签，以同一Release统一组织源码、完整处理后内容、报告、前端、测试证据及运行包。发布验证见Release中的RELEASE-VALIDATION.json，交付内容见[交付索引](00-交付索引.md)。

历史实验源码基线c171ac542fadb35db92586bd1e5a87c5602603fb，核对日期2026-10-09 UTC；提交副本是独立提交仓库，不带原项目提交历史。v1.0交付4810题与2646检索块，包含完整源码、运行包、文档与数据清单。既有容量验收为4808题快照，GPU实验为36题／4讲义；实验口径独立标注。

提交版包含依赖安全更新、FTS基础配置、解析预热保护、原子学习记录回写、查询索引与CTE优化、连接并行限制及独立写者通道、短同步请求连接复用，以及submission_*交付工具和测试用例。SOURCE_BASELINE.json记录258个基线源文件核对及提交版差异。编译dist记录源码摘要与构建时间，正式报告、证据及运行包通过标签和清单建立对应关系。

## 二、运行冻结与发布验证

运行库和FTS从只读事务中的内容白名单重建，保留题目与检索块编号、引用和判题配置；身份全新生成、个人行为表为空。打包前审查数据摘要、账号白名单、表计数、密钥与数据库完整性。SHA256SUMS校验运行包与截图证据包；发布后重新从GitHub下载并核对，再进行干净环境部署与登录验收。

源码、运行包和报告按v1.0标签统一组织。ACCESS.md仅包含本地虚构身份，线上评审凭据单独提供；公开前按PUBLICATION.md完成许可及数据授权确认。

## 三、GPU已完成实验与扩展协议

本轮在业务功能、并发一致性和外部API链路验收基础上，已完成独立4090D上的现有FP8基座与LoRA本地推理、批量吞吐和应用接入验证，见08报告及gpu-4090d证据目录；GPU实验与应用运行环境独立配置。实验登记型号、卡数、显存、功耗策略、CPU/RAM与容器配额、驱动/CUDA、torch/vLLM版本、基座与adapter哈希、量化、上下文长度、输入/输出tokens、batch/concurrency、预热次数和重复次数，支持按相同口径扩展。

固定至少三类负载：文本单请求推理、批量模型吞吐、embedding／rerank（若采用向量模式）。每组先预热，再重复至少5次，报告均值、中位、P95、首token、总生成、tokens/s、峰值显存；训练实验记录实际steps、有效batch、样本数、epoch、checkpoint与实测时长。

若对比双V100与租借显卡，固定模型、量化、提示、token长度与服务参数，分别报告设备可运行性、显存与速度，保证硬件对比条件一致。线上API端到端时延包含网络与供应商排队，测试环境GPU计算时间采用本地计时，两类指标分别报告。

## 四、实验与评价更新纪律

更新数据先保留清单与哈希；固定训练/验证划分，审查重复与teacher泄漏。模型能力评价使用独立人工金标，分别计量答案正确、首错位置、错因和引用支持。掌握度与复习效果采用伦理合规的真人长期样本与对照设计；合成画像用于流程及算法性质验证。

提交前完成代码优化后，重新运行受影响的单元、干净构建、关键HTTP和浏览器；并发相关代码重新串行运行10/25/50用户测试并核对落库。正式报告、证据目录与下载包采用最终冻结代码的完整实测，开发资料单独管理。按预定门槛验收，优化后通过复测形成新的正式结果，保留实测数值与源码对应关系。

## 五、补充材料安排

正式演示视频约279.175秒（4分39秒），与33页答辩PPT均按所有者确认的最终文件原样交付，仅统一文件名。已核验视频完整解码、文件摘要及访问入口，见[演示材料与文件校验](演示材料.md)。4090D推理基准已补齐；GPU训练时长、向量模式与跨设备对比按本协议扩展，训练权重和第三方语料依授权独立管理。本轮系统通过源码、处理后内容数据和可配置外部API运行，并提供本地GPU部署工具，支持独立部署与核心流程复现。
