# CourseLoop V1.0 演示材料

最终演示材料随同正式提交版本V1.0在Release统一交付：

- [答辩PPT：CourseLoop-V1.0-presentation.pptx](https://github.com/cccccrj/courseloop-competition-submission/releases/download/v1.0/CourseLoop-V1.0-presentation.pptx)，33页。
- [演示视频：CourseLoop-V1.0-demo.mp4](https://github.com/cccccrj/courseloop-competition-submission/releases/download/v1.0/CourseLoop-V1.0-demo.mp4)，约279.175秒，即4分39秒，符合3—5分钟要求。

PPT与视频使用项目所有者确认的最终文件，仅统一文件名，内容保持原样，不裁剪、不重新编码。视频展示学习中心、解题纠错、学习大厅及助教协同等流程；已核验文件结构、时长、完整解码和抽样画面。文件摘要见[media-manifest.json](media-manifest.json)，发布附件统一纳入SHA256SUMS。

展示材料中的历史数据快照与各专项指标按其原有日期、样本和评价定义阅读；当前交付的数据组成及完整测试结论分别见[数据说明](03-数据说明.md)和[测试报告](05-测试报告.md)。展示材料不替代正式报告及原始实验记录。


在空目录下载并校验：

```bash
gh release download v1.0 --repo cccccrj/courseloop-competition-submission \
  --pattern 'CourseLoop-V1.0-presentation.pptx' \
  --pattern 'CourseLoop-V1.0-demo.mp4' --pattern SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
```

私有阶段需先获得仓库访问权限。公开发布与许可授权按[PUBLICATION.md](../../PUBLICATION.md)另行确认。
