# CourseLoop 模型与算法说明

本文分别说明当前线上配置、可选工程实现和历史训练实验。参数从提交源码读取；历史训练指标在本文按各自实验条件汇总，本轮实测以正式证据目录为准。

## 一、当前模型配置与任务分工

线上模型：workhorse=deepseek-v3，expert=qwen3-max，reasoner=deepseek-r1，vision=qwen3-vl-30b-a3b-instruct，RAG=fts5。视觉通过智增增OpenAI兼容端点独立配置密钥，不改变文本请求路由；API密钥和签名密钥不交付。可按任务替换端点、凭据、model alias和温度。

视觉模型选择：转写使用instruct而非thinking模型，temperature=0.0、max_tokens=2048，并要求看不清写[?]、不补写图片没有的步骤。2026-10-09核查[智增增官方价目](https://doc.zhizengzeng.com/doc-3979947)，该模型列示输入0.00075元/千tokens、输出0.003元/千tokens（即0.75/3元每百万tokens）；页面另说明千问折扣，实际账单以账户计费为准，不把标价或估算作为实付费用。

| 配置／参数 | 默认值 | 含义 |
|---|---:|---|
| expert/workhorse/reasoner/vision温度 | 0.1 / 0.3 / 0.4 / 0.0 | 视觉采用低温忠实转写，其余为对应角色设置 |
| task diagnose/solve/grounded_qa/practice上限 | 768 / 1024 / 512 / 1024 tokens | ask_task路径的默认上限 |
| 独立任务温度 | 0.0 | 已配置独立任务路由时使用，否则回退workhorse温度 |
| 客户端HTTP超时 | 600秒，connect10秒 | 客户端默认重试；响应性能按实际链路测试结果评价 |
| CL_LLM_NO_THINK | False | 本地no-think微调模型可关闭Qwen3模板思考模式 |

参数适用范围：学习大厅使用ask_reasoner_stream，该路径当前由供应商默认输出限制控制；表中grounded_qa=512等上限适用于ask_task路径。token、final、citation、verify、error、done等SSE事件分别表示流、最终文、依据、校验、错误和结束。引用事件提供来源追溯，verify按实际校验类型提供检查结果；逐句事实支持需结合所引内容核查。

配置总入口：[config.py](../../backend/core/config.py)。当前线上API、历史训练与4090D推理分别见本节、第五节及 [08专项报告](08-GPU部署与性能报告.md)，采用各自模型与数据条件。

线上FTS5采用trigram索引与BM25排名，课程和doc_type过滤后返回统一Hit；top_n通常3。向量分支可选BGE-M3嵌入、Chroma持久库和BGE Reranker；默认top_k8、rerank_top_n3，设备auto。本轮采用轻量FTS5路线，向量权重由部署者另行准备，向量模型GPU时延按07扩展协议专项验证；已完成的本地文本GPU推理见08。

结构化分块常量MIN_CHARS120、MAX_CHARS1200、OVERLAP120；固定兜底窗口1000、重叠200。解析器按格式使用章节、页或标题路径进行结构化切分，固定窗口用于兜底。去重键为课程与归一化文本哈希；同文跨课程独立保留。引用定位到source/title_path/page_start/page_end，Word/TXT采用标题路径定位。

检索评价分层开展：历史42例评测检查指定来源与章节关键词，去重后来源锚点命中率为92.9%，等价来源在该口径下可能记为未命中；本轮四课程4例验证课程过滤与非空检索链路，4/4通过。检索相关性与生成回答正确率分别使用独立标注集评价。

## 三、确定性验证与诊断

数值验证：canonical JSON按kind分派choice/int/scalar/percent/bits/ipv4net/set。归一化支持字母集合、整数、容差浮点、百分比、位串、网段和集合。未知kind或解析失败返回None；numeric无法确定时业务可调用LLM作概念兜底。

代码验证：将代码、函数和测试样例送入独立Python子进程，限制CPU、地址空间并设置外部timeout，样例可标hidden。结果包含通过率和首个未通过样例；技术原文写入可审查字段，学生侧显示业务说明。当前提供资源受限执行能力，公网任意代码部署需另行配置系统调用、网络和文件访问隔离；敌对逃逸验证纳入专项安全测试范围。

规则验证：按expected_evidence／description匹配得分点，再按rubric score加权生成部分比例，为概念题提供可解释的评分依据。模型补充解释，复杂语义和争议结果结合人工复核。解题、练习和模考复用judge_answer，统一判分口径；模考逐题保存结果并支持断线续阅。

诊断：结构化输出correct、first_wrong_step、error_tags、diagnosis、reexplain/remediation。十类错因由受控taxonomy定义，并映射后续动作。careless必须有同知识点历史正确作答；首错标注在代码题与编号步骤题中口径不同，模型准确率须用独立人工标注再验证。

## 四、TutorGraph与学习模型

五状态、五级提示串联思路、提示、诊断、纠正、变式和复测。解析预热是后台任务，复用结果时校验原题身份。variant切换当前题目和参考答案，持久化快照支持服务重启后续接。变式生成与验证状态分别记录，异常或待验证结果按其实际状态处理。

正确更新：d=0.6+0.2×clip(difficulty/5)，h=1−clip(0.15×hints,0,0.6)，gain=0.22×d×h（教师确认额外0.08），m'=clip(m+gain×(1−m))。错误更新：drop普通0.18、稳定概念错误0.28，m'=clip(m−drop×(0.4+m))。结果四舍五入4位。

遗忘：m_eff=m×(0.3+0.7×0.5^(days/14))，保留部分基础记忆。状态not_started/learning/fragile/mastered/needs_review/misconception，掌握阈值0.8；状态函数接收原始掌握度并结合间隔判定，久未练的高掌握原值转needs_review，确保衰减处理口径一致。confidence函数1−exp(−attempts/3)与业务回写逐次增加0.15、上限0.95分别用于对应路径，均为工程启发式，统计概率标定列入后续研究。

优先级：2×(1−mastery)+0.5×error_freq+0.05×max(0,days_since−7)+前置知识0.5；未探索且无错误时基础项×0.75。间隔1/3/7/14/30天；答错回退stage0，hints≥2不进阶。任务按mastery<0.4重讲基础、<0.7强化、其余查漏组织；全局预算按课程分值分摊，滚动排期有core/optional与到期窗。

当前常数采用可解释的工程启发式，合成轨迹用于流程与算法性质验证。长期真人数据标定、遗忘曲线与IRT拟合作为后续独立研究方向。

## 五、历史SFT与GRPO：原理、实现、参数

QLoRA：基座Qwen3-14B NF4，使用Unsloth、transformers/datasets/TRL开展低秩适配多任务训练。通过messages格式和Qwen3 chat template准备样本，只对assistant段计算loss。rank16、alpha32、max_seq4096、microbatch2、accum4、lr2e-4、2epochs；脚本支持adapter增量和checkpoint resume。

历史数据：8899 train、467 held-out验证；增量新数据2850与旧样本replay形成4563；GRPO旧集2800，规模按原报告归档。本轮交付方法、源码与聚合报告；复训另行准备获授权的原始数据与权重，并重新完成资产审计、查重和划分冻结。

GRPO从SFT adapter续训，对每题多候选采样，按组相对奖励优化；默认G=6，脚本中的格式、字段和可验证答案奖励见grpo_rewards.py。评价分别报告格式合法率、teacher一致性和基于独立人工金标的答案正确率，确保各指标含义清晰。

历史训练聚合结果：总体JSON合法率由SFT93.8%提高至+GRPO94.9%，120题抽样teacher答案一致率两组均为57.5%。这组实验分别记录结构化输出改善与答案一致性表现，为后续奖励设计提供依据。以上指标采用历史实验的数据与模型条件；本轮GPU推理性能按08专项报告的独立协议评价。

## 六、复现方式与技术选型

本轮支持CPU复现原创单选、代码基准、掌握度性质、FTS链路与业务契约；配置自有API密钥可复现实时讲解与视觉转写链路。同时已在4090D上加载现有Qwen3-14B-FP8与rank16／alpha32 LoRA，完成本地GPU推理和应用接入验收，参数、依赖锁、权重SHA256及实测结果见08。该推理实验使用FP8基座，历史SFT训练采用NF4，两种量化条件分别记录；本轮按现有模型推理执行。SFT／GRPO复训及向量GPU基准按07扩展协议另设独立环境；requirements-research提供可选研究依赖参考。

查询层采用人工编写的参数化SQL、热查询索引与课程范围CTE物化，实现业务查询优化。技术路线聚焦检索、信息处理、判分与学习调度。GPU实验登记硬件、驱动、模型哈希、提示／数据、tokens与重复次数；后续扩展依 [07协议](07-版本冻结与后续更新.md)保持同一证据口径。
